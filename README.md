# AutoCAD Practice

AutoCAD 2D drafting exercises created through self-study, as part of my 
transition from a DevOps/DevSecOps background into mechanical/product 
(NPD) design engineering.

## Contents
- 2D drafting exercises built from scratch in AutoCAD
- Practice drawings for mechanical components (brackets, profiles, 
  cylindrical parts with hole patterns, etc.)
- Concepts carried over from SolidWorks, re-implemented as AutoCAD 
  drafting workflows

## Why this repo
Documenting hands-on drafting practice while building toward roles in 
product/design engineering — showing consistent, self-directed skill 
development alongside a mechanical engineering foundation.
